01

Research

My group studies how machine learning can make networked systems more intelligent, adaptive, and secure. We develop robust learning methods for encrypted traffic, distributed and evolving data, and resource-constrained edge environments, with an emphasis on solutions that remain effective under real-world change.

I am always happy to talk about these topics with students and collaborators.

  1. Network intelligence

    Machine learning for encrypted traffic classification, network monitoring, and intelligent network management.

  2. Robust and adaptive learning

    Continual learning, distribution shift, concept drift, class imbalance, and out-of-distribution detection.

  3. Federated and distributed AI

    Privacy-aware and communication-efficient learning across decentralized network and edge environments.

  4. Network and IoT security

    Learning-based security, intrusion detection, access control, and trustworthy mechanisms for IoT, vehicular, and edge systems.
